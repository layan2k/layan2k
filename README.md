## 🚀 About Me

I am a **Data Engineer & Infrastructure Specialist** transitioning away from general software development to focus exclusively on end-to-end data systems. I bring strong hands-on experience in **relational database architecture (SQL Server, PostgreSQL)**, **ETL orchestration (SSIS, Python)**, and **Linux/Containerized deployments**.

* 🔭 **Current Focus:** Engineering fault-tolerant ETL/ELT pipelines, dimensional modeling, and database query optimization.
* 🌱 **Learning Path:** Expanding into **Apache Airflow**, **PySpark**, **Data Lakehouses**, and cloud-native data warehouses (**Snowflake / BigQuery**).
* ⚡ **Core Strengths:** SQL Server Integration Services (SSIS), T-SQL optimization, Dockerized data environments, and automated data processing.
